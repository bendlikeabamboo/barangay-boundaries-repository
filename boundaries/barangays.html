Barangays

Download all 42,026 Philippine barangay boundaries as a single GeoJSON file enriched with PSGC codes, derived from NAMRIA shapefiles and PSA PSGC snapshots.

Author

Manuel Balmeo

Download all Philippine barangay boundaries as one GeoJSON file, every polygon tagged with its canonical PSGC code. With 42,026 barangay polygons (snapshot 2023-10-24), this is the lowest-level administrative boundary dataset for the Philippines.

Download

The barangay file is available through all three pipeline tiers. The Hierarchical tab is the curated, recommended download; Enriched and Raw are intermediate pipeline stages documented for traceability.

  • Hierarchical (curated / recommended)
  • Enriched (pipeline stage)
  • Raw (pipeline stage)

Per-class extract — barangays only:

curl -LO https://github.com/bendlikeabamboo/barangay-boundaries-repository/releases/download/v2026.4.13.0/barangays.geojson

ADM4 file with PSGC codes (in-repo only):

curl -LO https://raw.githubusercontent.com/bendlikeabamboo/barangay-boundaries-repository/main/2023-10-24/enriched_t0p005/adm4.geojson

NAMRIA-converted, pre-enrichment (in-repo):

curl -LO https://raw.githubusercontent.com/bendlikeabamboo/barangay-boundaries-repository/main/2023-10-24/raw_t0p005/adm4.geojson

The enriched and raw tabs above are intermediate pipeline stages; see Releases & versioning for the tag convention and the in-repo stage paths.

Properties per feature

Each barangay feature includes psgc_code (10-digit), psgc_name, psgc_status, match_confidence, plus the original NAMRIA attributes (e.g. ADM4_EN, ADM4_PCODE).

Use it

Load into geopandas, QGIS, or any GeoJSON reader, then join on psgc_code to census, health, election, or financial data keyed by Philippine Standard Geographic Code.

Limitations

Warning

Coverage gaps in this barangay layer:

  • ~198 PSGC barangays (mostly in BARMM and Metro Manila) — and ~230 PSGC entities in total — have no NAMRIA polygon.

  • 6 features could not be resolved to a PSGC entity (unresolved.geojson).
